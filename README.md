# Мастерская тестов

Учебный проект на React и JavaScript для первого знакомства с тестированием фронтенда. На примере одного списка задач ты проверишь чистую функцию, форму, связку компонентов и пользовательский сценарий в браузере.

## Запуск

Понадобятся Node.js 22.13+ из ветки 22 либо Node.js 24+ и npm. Открой терминал в папке проекта.

```sh
npm ci
npm run dev
```

`npm ci` устанавливает зависимости из `package-lock.json` с зафиксированными версиями. `npm run dev` запускает Vite, локальный сервер для разработки. Открой адрес из терминала.

В приложении можно добавить задачу, отметить её выполненной, переключить фильтр и перезагрузить страницу. Список хранится в `localStorage` браузера. Справа от списка (на узком экране ниже) есть четыре раскрывающихся шага с командами для запуска тестов.

## Порядок изучения

Начни с [обзора видов тестирования](docs/testing-guide.md#testing-types). В нём отмечено, какие проверки уже есть в проекте и когда пригодятся остальные.

1. [Юнит-тест функции](docs/testing-guide.md#01) — проверь результат для разных входных данных в Node.js.
2. [Тест компонента](docs/testing-guide.md#02) — заполни React-форму и проверь её реакцию в jsdom.
3. [Интеграционный тест](docs/testing-guide.md#03) — проверь совместную работу формы, списка, фильтров и счётчика.
4. [Сквозной тест](docs/testing-guide.md#04) — открой приложение в Chromium и проверь сохранение после перезагрузки.

В [практикуме](docs/testing-guide.md) для каждого шага есть команда, объяснение и задание. В самих тестах есть комментарии к новым приёмам.

## Команды

- `npm test` — один раз запустить все тесты Vitest.
- `npm run test:watch` — перезапускать тесты при изменении файлов. Для выхода нажми Ctrl+C.
- `npx playwright install chromium` — запустить установленный в проекте Playwright и скачать нужную ему сборку Chromium. Chromium — браузер с открытым исходным кодом, на котором основан Google Chrome. Он нужен для четвёртого урока.
- `npm run test:e2e` — запустить сквозной тест. Playwright сам запустит свой сервер Vite на порту 4173.
- `npm run test:e2e:ui` — открыть окно Playwright и пройти тест по шагам.
- `npm run build` — собрать приложение в папку `dist`.

Vitest и Playwright можно запускать в отдельном терминале, пока приложение открыто на сервере разработки.
